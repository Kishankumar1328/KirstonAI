## Tech Stack
- **Frontend**: React 18 + TypeScript + Vite
- **Backend**: Python + FastAPI
- **Database**: PostgreSQL

## Getting Started

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Database
```bash
psql $DATABASE_URL -f db/schema.sql
psql $DATABASE_URL -f db/seed.sql
```
