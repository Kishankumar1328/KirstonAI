# Task Management Platform
> Generated by **KirstonAI Coding Agent** — Task Manager

## Requirement
> "Build a complete real-time Task Management system with authentication and FastAPI backend."

## Features
- Create and manage tasks
- Set priority (low/medium/high)
- Task status workflow (todo → in_progress → done)
- Filter by status and priority
- Task assignment and due dates

## API Endpoints
| Method | Path | Description |
|--------|------|-------------|
| GET | /api/v1/tasks | List tasks (filter: ?status=) |
| POST | /api/v1/tasks | Create task |
| PATCH | /api/v1/tasks/{id} | Update task status/priority |
| DELETE | /api/v1/tasks/{id} | Delete task |

## Setup
```bash
cd backend && pip install -r requirements.txt && uvicorn app.main:app --reload
cd frontend && npm install && npm run dev
```
